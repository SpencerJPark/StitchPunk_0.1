# 0004: Voice input modes and record key

Status: accepted (2026-09-28)

## Decision
Support both push-to-talk and always-on (voice activity detection), chosen in settings. The record key is rebindable, defaults to backtick, and the tool warns when it clashes with a game input binding. An on-screen record button is available as an alternative.

## Why
Any fixed key (Space especially) can be a game control. Some developers want clean, deliberate notes; others want to talk freely while playing.
