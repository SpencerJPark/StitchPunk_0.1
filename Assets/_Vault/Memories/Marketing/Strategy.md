# Marketing Strategy — Audience Building

## Core Angle

**"Teaching DOTS game development through a real game."**

Spencer is building *Stitch Punk* on Unity DOTS — a powerful but poorly-documented stack that most Unity developers have heard of but haven't used. This creates a dual audience:

1. **Unity developers** curious about DOTS — they watch for the technical content, stay for the game
2. **Indie game fans** into Victorian aesthetics, necromancy, factory builders, and mystery narratives

Both audiences build together. The devlogs serve both.

---

## Content Cadence

One devlog per major system shipped. Tied to [[Tasks/Spencer/Content_Recording]] milestone gates:

| Devlog | System milestone | Estimated timing |
|---|---|---|
| #1 — Why DOTS | NPC AI bug fixed + citizens working | As soon as possible — this unblocks going public |
| #2 — Motivation AI | Scene 05 dining hall playable | After dialogue system ships |
| #3 — Revival system | Scene 03 playable end-to-end | Relatively soon — systems mostly built |
| #4 — RTS tournament | Scene 07 playable | After RTS mode ships |

Do not go public before Devlog #1 is ready. The NPC AI bug makes the game look broken — fix it first.

---

## Platform Priority

1. **YouTube** — primary. Long-form technical content lives here. Algorithm-friendly for "Unity DOTS" and "indie devlog" searches.
2. **Twitter/X** — clips, GIFs, progress screenshots. Developer community is active here. Tag #indiedev #gamedev #unitydots
3. **TikTok** — optional, lower priority. Short clips only. "100 NPCs with real emotions" type hooks work here.
4. **Reddit** — r/IndieDev, r/Unity3D, r/gamedev for major milestones. Don't spam.

---

## Target Audience

| Audience | Why they care | What to show them |
|---|---|---|
| Unity DOTS developers | Technical content is rare and valuable | Performance graphs, ECS inspector, code architecture |
| Indie dev community | Following a project from zero to demo | Behind-the-scenes, honest progress, failures and fixes |
| Victorian / steampunk fans | Aesthetic and setting | Art showcases, world-building details |
| RTS fans | Horde mechanics + factory economy | Gameplay footage once RTS mode is playable |
| Mystery / narrative fans | The murder mystery hook | Story reveals, suspect system, professor's voice |

---

## Milestones for Going Public

Do not post publicly before these are done:

- [ ] NPC AI bug fixed (citizens visibly living their lives)
- [ ] Scene 03 playable end-to-end (the core loop — raise dead, give orders)
- [ ] Devlog #1 script drafted and recorded

After these: post Devlog #1 as the announcement + start building audience while continuing development.

---

## Tone of Voice

- **Honest and direct.** Not hype-driven. Show real problems and how you solved them.
- **Technical but accessible.** Explain ECS as "components of data instead of objects with methods" — not with jargon.
- **Enthusiastic about the craft.** The love for the systems shows.
- **Self-aware about scope.** "This is a solo dev project" is not a weakness — it's relatable.
